# TLcoachfit

Application web de suivi d'entraînement.

## V3 — Programme personnalisé
- Choix de l'objectif : prise de muscle, perte de graisse, cardio/endurance, remise en forme
- Choix du niveau : débutant, intermédiaire, avancé
- Choix de 3, 4 ou 5 jours d'entraînement
- Durée cible des séances
- Génération automatique d'une semaine avec **2 jours de repos**
- Calendrier cliquable : choisir une date pour voir la séance prévue
- Chronomètres et suivi cardio
- IMC, profil, historique et statistiques
- Logo TLcoachfit
- Emplacement prévu pour les vidéos coach IA de 15–20 secondes

## GitHub Pages
Mettre `index.html`, `README.md` et le dossier `assets/` à la racine du repository `TLcoachfit`, puis activer Pages sur `main` / root.
