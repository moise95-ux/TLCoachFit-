# TLcoachfit

Application web de suivi d'entraînement et de progression.

## Fonctionnalités
- Programmes musculation, perte de graisse, cardio et HIIT
- Chronomètres
- Suivi tapis de course : durée, distance, vitesse, calories estimées
- IMC et profil
- Calendrier et historique
- Statistiques
- Logo et identité TLcoachfit
- Sauvegarde locale via `localStorage`

## GitHub Pages
1. Créer un repository nommé `TLcoachfit`.
2. Importer tout le contenu de ce dossier à la racine du repository.
3. **Settings → Pages → Deploy from a branch → main → /(root)**.
4. Enregistrer puis ouvrir l'URL GitHub Pages.

Conçu comme prototype front-end sans backend.
